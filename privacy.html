Privacy Policy, Relaxing Adhkar Uploader

Last updated: 19 November 2026

  1. Who uses it. Relaxing Adhkar Uploader is used only by the owner of the Relaxing Adhkar YouTube channel, to upload, schedule and manage videos on that channel. It is not offered to anyone else.
  2. YouTube API Services. The tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy applies: https://policies.google.com/privacy.
  3. Data accessed. Only the channel's own videos, their titles, descriptions, thumbnails and schedule, and the channel's own statistics.
  4. Data about viewers. None is collected, stored or shared. The tool never reads comments or viewer accounts.
  5. Storage. The access key stays on the channel owner's private server. It is never shared.
  6. Revoking access. Access can be removed at any time at https://myaccount.google.com/permissions.
